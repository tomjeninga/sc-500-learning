# Contributing

Thanks for helping improve this SC-500 study repository.

## Contribution goals

This repo is intended to be a practical, community-friendly study companion for:

- Exam SC-500
- hands-on Azure and Microsoft security practice
- modern cloud and AI security topics

## Good contributions

- Fix outdated portal paths, service names, or exam-objective alignment
- Improve lab clarity, validation steps, or cleanup guidance
- Add missing Microsoft Learn / Microsoft Docs references
- Tighten cost warnings, prerequisites, or licensing assumptions
- Improve AI security, Purview, Sentinel, Defender, Entra ID, or governance coverage

## Contribution guidelines

1. Keep the focus on **official SC-500 study guide topics**
2. Prefer **Microsoft Learn** and **Microsoft Docs** links over third-party sources
3. Use **managed identity** and secure-by-default guidance in all samples
4. Add a **Validate** section to hands-on content
5. Add **Cleanup** guidance for any billable resource
6. Avoid real tenant IDs, subscription IDs, secrets, keys, or screenshots with sensitive data
7. Prefer generally available features unless a preview feature is explicitly called out as commonly used

## Before opening a PR

- Check that the content still maps to the official SC-500 study guide
- Keep wording general and community-friendly
- Run the existing markdown lint workflow locally if possible

## What this repo is not

- Not an exam-dump repository
- Not a replacement for official Microsoft Learn
- Not a complete catalog of every Azure security feature
